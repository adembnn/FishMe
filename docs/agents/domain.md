# Documentation du domaine

Un seul contexte : le dépôt est une seule app.

## Lire avant d'explorer

- `GLOSSARY.md` à la racine, s'il existe (sinon, continuer sans le signaler).
- `docs/adr/` : lire les ADR qui touchent la zone à modifier. Aujourd'hui, les décisions sont dans `docs/architecture.md`, `docs/vision.md` et `CLAUDE.md` (datées).

## Pour le vocabulaire du produit

Les mots déjà fixés dans `CLAUDE.md` et `docs/` font foi : « rareté dans les relevés OFB », « liste de contrôle », « la carte », « Pescedex » (collection seulement), « station », « spot ». Ne pas inventer de synonyme.
