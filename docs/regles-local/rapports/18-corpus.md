Introuvables : aucun classement en catégories à part (le permanent le contient sans doute) ; arrêtés de réserves temporaires de la Fédération (écluses du Charenton) non publiés en PDF ; fichiers non obtenus depuis cher.gouv.fr (bloqué), copies tierces utilisées.
À savoir : contradiction possible à lire : le Code donne 50/40 cm, le Cher relève brochet à 60 cm, sandre 50 cm (cat. 2), black-bass 30 cm selon la synthèse fédérale ; vérifier dans le texte signé. L'ouverture brochet en 1re catégorie est le 25 avril. Le permanent 2019 est ancien : des articles ont pu être rendus caducs par le Code.
