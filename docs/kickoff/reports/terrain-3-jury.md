### 1.4 Monétisation et philosophie publiées
- MWM publie que le paywall est la surface « la plus sensible au revenu » ; le test A/B de paywall est « le travail à plus fort ROI ». Source : https://mwm.ai/glossary/paywall
- Conseil MWM : placer le paywall après la valeur, pas avant ; un hard paywall à l'ouverture sacrifie la conversion long terme ; tester essai 3 j vs 7 j. Source : https://mwm.ai/guides/app-monetization-strategies
- Taux de payeurs : hypothèse de planification ~6 % (souvent bien moins). Source : https://mwm.ai/guides/app-monetization-strategies
- Rétention : médiane D1 27,3 %, D7 9,2 %, D30 3,9 % ; top décile D30 10,9 % ; « la rétention est le multiplicateur de LTV ». Source : https://mwm.ai/guides/how-to-improve-app-retention
- Time-to-value : différer création de compte, permissions, paywall, tutoriel ; définir UN jalon d'activation. Source : https://mwm.ai/guides/how-to-improve-app-retention
- Modèle hybride (abonnement/IAP + pubs pour non-payeurs), prix localisés par pays. Source : https://mwm.ai/guides/app-monetization-strategies
- Valeurs internes : « Craft things people want », « Fast always wins », « Innovation over invention ». Source : https://mwm.ai/company
- Ce qu'ils achètent/publient : apps avec traction, jugées sur cohortes, LTV, rétention, payback, « pas un pitch deck ». Source : https://musicworldmedia.com/press et https://mwm.ai/mwm-publishing
- Publishing = partage de revenus, MWM finance l'acquisition d'utilisateurs, sans frais initiaux ; test UA à petite échelle sur régies avant l'accord. Source : https://mwm.ai/pricing et https://mwm.ai/publishing
- Prix des abonnements MWM AI : Pro 49 $/mois, Pro+ 149 $/mois (pour concevoir ses propres apps, pas des prix d'apps grand public). Source : https://mwm.ai/pricing
- Prix et essais des apps grand public (edjing, Beat Maker, Stemz) : non obtenus [?]. Piste : fiches App Store, ex. https://apps.apple.com/FR/app/id493226494 (non lue).

### 1.5 « Spark Flash SDK » (public)
- SDK mobile iOS et Android : analytics, monétisation, mise à l'échelle ; intégré par défaut aux apps générées par MWM AI, intégrable par tout développeur. Source : https://mwm.ai/sdk-terms-of-service
- Fonctions : suivi des achats in-app et abonnements, analyse d'usage dans MWM Console, monitoring. Source : https://mwm.ai/sdk-terms-of-service
- Données : ID d'installation, infos appareil, plantages, MetricKit, IP/localisation approximative, transactions si activées. Pas de carte bancaire. Source : https://mwm.ai/sdk-terms-of-service
- Interdit : apps pour moins de 13 ans, données sensibles. À respecter pour le choix du public cible. Source : https://mwm.ai/sdk-terms-of-service
- Le SDK MWM regroupe tracking, monétisation, paywalls modifiables sans mise à jour, attribution, pubs, revenus. Source : https://mwm.ai/mwm-publishing
- Implication : le jury voit les événements d'activation et de paiement que l'app envoie. Instrumenter l'activation et le paywall est probablement valorisé [?] (déduction).
