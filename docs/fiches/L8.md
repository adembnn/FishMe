# L8 Amis
B (Mac) · branche `lot/amis` (ta copie de travail du projet) · étape E8 · 10 à 18 h (estimation) · vendredi 16 oct., après L5, si Adem choisit L8 avant L7 ; jamais dans la version soumise jeudi

## But
Il invite un ami par un lien. Chacun voit le Pescedex (la collection) de l'autre : les cartes, jamais les coins exacts. Le relecteur d'Apple (l'employé qui teste l'app avant sa publication) ne peut pas prouver ce lot seul (refus R5 de `app-store.md`) : il reste hors du build soumis jeudi (la version envoyée à Apple).

## Avant de commencer
- [ ] Adem a choisi l'outil (`reports/amis.md` recommande CloudKit, la base d'Apple, avec un partage `CKShare`, l'invitation de partage ; SwiftData, la base locale d'Apple, reste local). Preuve : le choix est écrit dans `CLAUDE.md`
- [ ] Équipe payante MWM, capacité iCloud (une autorisation Apple liée à l'identifiant de l'app) et clé `CKSharingSupported` posées par A (une équipe gratuite n'a pas iCloud). Preuve : le conteneur (le compartiment iCloud de l'app) `iCloud.<identifiant>` existe dans Xcode (le logiciel d'Apple qui fabrique l'app)
- [ ] 2 iPhones en iOS 27, 2 comptes iCloud différents, même type de build. Preuve : les deux comptes sont notés
- [ ] L4 fusionné (les cartes à partager existent ; `lots.md` : L8 dépend de L4 et de l'outil choisi par Adem). Preuve : `git log` (l'historique des enregistrements)

## Dossiers
- Permis : `App/Amis/` seulement. Interdit : tout `*.xcodeproj` (le fichier central du projet Xcode), `Packages/Core`, les autres dossiers de `App/`.

## Contrat
- Une carte partagée ne contient que : identifiant, espèce, rareté, date, taille, bredouille oui ou non, département, image PNG détourée sans GPS. Jamais de coordonnées, de nom de coin, de texte libre ni de pseudo.
- Le lien d'invitation ne s'ouvre que pour les personnes invitées. Chaque ami voit seulement ce qu'on lui a partagé.
- Signaler une carte (e-mail suivi, réponse sous 24 h), retirer un ami (coupe le partage et masque ses cartes), supprimer ses cartes partagées, contact publié (règle 1.2).
