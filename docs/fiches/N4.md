## But
Dans le profil, une section « Mes records » : un souvenir par espèce (la plus grande prise, montrée comme une carte « Trophée » quand elle dépasse le seuil de D2), trois compteurs (sorties, espèces trouvées, bredouilles) et, quand une prise dépasse le souvenir précédent de son espèce, un bandeau doux. Tout est calculé sur l'iPhone, depuis les cartes du Pescedex et les sorties terminées. Rien n'est envoyé, rien n'est partagé, aucun classement.

**Le record est un souvenir, pas un objectif.** Conséquences écrites dans le contrat : aucun XP, aucun point, aucun niveau, aucun décor ni aucune récompense ne dépend d'une taille ni d'une rareté (CLAUDE.md : XP indépendants de la rareté et de la taille, pas de chasse au gros). `BadgeProfil` (qui se gagne avec le nombre de cartes) n'est pas touché et ne lit pas `Records`. Aucun mot de défi, de classement, de « meilleur », de « battre ».

## Contrat

### Types de `Core` (purs, Foundation seulement, testables sous Linux)
Fichier `Packages/Core/Sources/Core/Records/Records.swift`. Tous `Sendable, Equatable, Hashable, Codable`.
```swift
public struct RecordEspece: Identifiable {
    public var espece: Espece
    public var priseID: UUID          // la prise qui tient le souvenir
    public var longueurCm: Double
    public var mesure: MethodeMesure?
    public var date: Date
    public var lieuFlou: String?
    public var nombreDePrises: Int    // vraies prises de l'espèce, avec ou sans taille
    public var estTrophee: Bool       // longueurCm strictement > seuil (D2), faux sans seuil
    public var id: String { espece.id }
}
public struct CompteursPersonnels {
    public var sorties: Int           // sorties terminées (fin != nil)
    public var especesTrouvees: Int   // espèces distinctes ayant une carte non exemple (D3)
    public var bredouilles: Int       // sorties terminées sans vraie prise
}
public struct BilanRecords {
    public var records: [RecordEspece]      // triés par date décroissante, puis id
    public var especesSansTaille: [Espece]  // vraies prises mais aucune longueur valide
    public var compteurs: CompteursPersonnels
}
public enum EvenementRecord: Equatable {
    case aucun
    case premiereTaille                       // première longueur valide de l'espèce : pas de bandeau
    case nouveauSouvenir(ancienCm: Double, nouveauCm: Double)
}
public enum MoteurRecords {
    public static func bilan(prises: [Prise], sorties: [Sortie],
                             seuilTropheeCm: (Espece) -> Double?) -> BilanRecords
    public static func evenement(pour prise: Prise, parmi autres: [Prise]) -> EvenementRecord
}
```
Règles, toutes testées :
- Une prise **compte** pour un record si `origine == .priseReelle`, `exemple == false`, et `longueurCm` est fini et strictement positif. Sinon la longueur est « inconnue ».
- Comparaison des longueurs **arrondie au millimètre** (0,1 cm) : 72,04 et 72,0 sont égales.
- Le souvenir d'une espèce est la plus grande longueur ; à égalité, la prise **la plus ancienne** le garde (la dernière ne le déplace pas).
- `evenement` : `.nouveauSouvenir` seulement si la longueur de `prise` est strictement plus grande (au mm) que toutes celles de `autres` pour la même espèce, et qu'il y en a au moins une ; `.premiereTaille` s'il n'y en a aucune ; `.aucun` dans tous les autres cas (égalité, plus petite, sans taille, déclarée, exemple). `autres` peut contenir `prise` elle-même : elle est ignorée (même `id`).
- `compteurs.sorties` ne compte que les sorties avec `fin != nil`. Une sortie est **bredouille** si, une fois retirés les prises d'exemple et déclarées, il ne lui reste aucune prise (même définition que `FormatSortie.prises` de `App/Session/`). `bredouilles <= sorties` toujours.
- `especesTrouvees` : espèces distinctes par `espece.id` parmi toutes les cartes non exemple, déclarées comprises (D3).
- Les `estTrophee` viennent du paramètre `seuilTropheeCm` ; `Core` ne connaît aucun pourcentage.
- Aucune fonction ne retourne de points, de score, de niveau ni de rang.

Seuil : une ligne `func seuilTropheeCm(espece: Espece) -> Double?` dans `MoteurEspeces` (renvoie `p95Cm`, `nil` s'il manque), derrière un protocole à part `ServiceSeuilTrophee` sur le modèle de `ServiceLongueurPlausible`, pour ne casser aucun faux service. Le nom du champ de données du seuil est interne : l'app ne parle que de `seuilTropheeCm`.

## Critères d'acceptation (mesurables)
Tous les cas numériques sont des tests de `Packages/Core/Tests/CoreTests/Records/RecordsTests.swift` (Swift Testing), sauf mention.

Records :
1. **Aucune prise** : `bilan(prises: [], sorties: [])` donne `records == []`, `especesSansTaille == []`, compteurs `0/0/0`.
2. **Une seule prise** (brochet 62,0 cm) : un seul record, `nombreDePrises == 1`, `priseID` = cette prise ; `evenement(pour:, parmi: [])` = `.premiereTaille`.
3. **Deux prises, la seconde plus grande** (60,0 puis 72,5) : `evenement(pour: seconde, parmi: [première])` = `.nouveauSouvenir(ancienCm: 60,0, nouveauCm: 72,5)` ; le bilan garde 72,5.
4. **Tailles égales** (72,0 le 1er sept., 72,0 le 5 oct.) : le record reste sur la prise du 1er sept. ; `evenement` de la seconde = `.aucun`.
5. **Égalité au millimètre** : 72,04 contre 72,0 = `.aucun` ; 72,1 contre 72,0 = `.nouveauSouvenir`.
6. **Taille inconnue** : une prise sans `longueurCm` ne crée pas de record ; son espèce figure dans `especesSansTaille` si elle n'a aucune autre prise mesurée, et pas si une autre prise de la même espèce est mesurée ; `evenement` = `.aucun`.
7. **Longueur invalide** (0, -3, `.nan`, `.infinity`) : traitée comme inconnue, jamais de plantage.
8. **Prise plus petite** que le souvenir : `.aucun`, le bilan inchangé.
9. **Carte déclarée** (même avec une longueur dans les données) et **carte d'exemple** : jamais de record, jamais de `.nouveauSouvenir`.
10. **La prise elle-même dans `autres`** : ignorée (même `id`), même résultat que sans.
11. **Plusieurs espèces** : un record par espèce ; tri par date décroissante, puis `id` ; deux appels sur le même jeu donnent le même ordre.
12. **Trophée** : seuil 90,0 cm ; 90,0 cm = `estTrophee == false` (strictement plus grand), 90,1 cm = `true` ; seuil `nil` = `false` sans effet sur le record.
13. **La taille ne change ni la rareté ni les compteurs** : deux jeux de prises identiques sauf les longueurs donnent les mêmes `compteurs` et les mêmes `especesTrouvees`.

Compteurs :
14. **Sorties** : 3 sorties terminées et 1 en cours (`fin == nil`) donnent `sorties == 3`.
15. **Bredouilles** : 3 sorties terminées dont une sans prise, une avec seulement une prise d'exemple, une avec une vraie prise : `bredouilles == 2`, `bredouilles <= sorties`.
16. **Espèces trouvées** : 4 cartes (2 brochets, 1 sandre, 1 déclarée de perche, 1 exemple de carpe) : `especesTrouvees == 3` (D3).
17. **Aucune sortie, des cartes seulement** (cartes déclarées du premier lancement) : `sorties == 0`, `bredouilles == 0`, `especesTrouvees` = nombre d'espèces déclarées.

## Pièges
- Le mot « Trophée » promet une récompense. Parade : étiquette sobre, jamais de couleur de rareté, jamais d'XP, jamais de pourcentage affiché ; le test de grep du critère 21.
