## But
L'étude de marché est livrée le 19 oct. : cinq rapports dans `reports/marche/` (lire `reports/marche/README.md` pour la liste et la façon de les lire). La suite est la veille : une fois par mois, rejouer les mêmes outils gratuits sur les mêmes concurrents et noter ce qui a bougé.

## Avant de commencer
- [ ] Le venv existe : `python3 -m venv outils/marche/.venv && outils/marche/.venv/bin/pip install requests google-play-scraper`.
- [ ] Tu as lu `reports/marche/methode.md` (§2 où les chiffres mentent, §8 les outils). Preuve : tu sais qu'un chiffre sans source est refusé par le vérificateur.

## Dossiers
- Permis : `outils/marche/`, `reports/marche/`.
- Interdit : tout le reste. Les données collectées (`reports/marche/donnees/`) et le venv ne sont jamais commités.

## Contrat
- `outils/marche/.venv/bin/python outils/marche/verifier.py reports/marche/` affiche « 0 trou » ; `outils/marche/.venv/bin/python outils/marche/test_verifier.py` vert ; aucun fichier de `reports/marche/donnees/` ni de `outils/marche/.venv/` dans git ; chaque rapport nomme la décision qu'il débloque.
- Aucun outil payant, aucune clé API : si une source demande une clé, on s'arrête et on le dit.

## Test « fini »
`outils/marche/.venv/bin/python outils/marche/verifier.py reports/marche/` affiche « 0 trou », et `git diff --name-only main` ne montre que `outils/marche/` et `reports/marche/`.

## Pièges
- Le flux RSS App Store est vide pour certains pays : c'est connu, le dire au lieu d'inventer.
- `search.json` de Reddit renvoie 403 : `reddit.py` replie sur `search.rss` (score et commentaires vides alors).
- `google_play_scraper.search` est cassé : trouver le package sur `play.google.com/store/search`.
- Les données tirées vont dans `reports/marche/donnees/`, jamais dans git.

## Si ça coince
- Une source refuse ou demande une clé : note dans le point d'étape, ne pas inventer de chiffre.
- Un pays n'a pas de donnée : écrire « non trouvé [?] », pas une estimation déguisée.
