# US17 Poissons signalés dans l'app (fiche d'un plan d'eau ou d'un accès)
B (Titouan) · branche `lot/us-poissons-app` (créée par `scripts/lot.sh US17`) · étapes : E2 E4 · travail d'une session seule : 1 à 2 j · lancé le 7 nov. au soir (« je t'ai demandé tous les États », Titouan)

## But
La fiche d'un plan d'eau ou d'un accès US affiche « Poissons signalés ici » en images, avec source, date et niveau de confiance, puis le bloc de règles `BlocReglesUS`. Textes en anglais pour la région US. Zone sans donnée : message honnête avec le lien de l'agence. Espèce sans image : « image à venir », jamais l'image d'une autre espèce.
Décisions du 7 nov. (`CLAUDE.md`) : voir la colonne « Dépend de » de `docs/lots.md`.

## Dossiers
- Permis : `App/CarteUS/`, `AppTests/CarteUS/`, `AppTests/PoissonsUS/`.
- Interdit : tout le reste du dépôt, y compris les dossiers des autres lots ; `App/RootView.swift` est à L25 : une ligne à y ajouter se demande à la session principale.

## Contrat
- Aucun texte affiché ne contient « autorisé », « allowed », « legal », « tu peux la garder » ni « you can keep it » ; jamais « accès libre » ni « pêche autorisée ici » : seulement « accès public listé par <agence> ».
- Source inaccessible (403, anti-bot, connexion, CAPTCHA) : jamais contournée ; l'État est marqué « partiel » avec la raison. User-Agent « FishMe-data/1.0 », pause entre requêtes, robots.txt respecté.
- Les poissons toujours en images, jamais une liste de noms seule ; aucune rareté affichée.
- La France ne change pas de comportement.
- Aucune donnée lourde ni photo dans git hors des fichiers embarqués prévus par le lot ; la source et la licence de chaque fichier sont écrites.
- Un test par morceau ; la suite du lot est verte avant de dire « fini ».

## Test « fini »
Commande de fusion : `scripts/fusionner.sh lot/us-poissons-app`. `xcodebuild test … -only-testing:BuildChallengeTests/PoissonsUSTests` vert ; `grep -rniE "autoris|allowed|legal|tu peux la garder|you can keep"` sur les textes ajoutés ne trouve rien ; en région France rien ne change.
Puis `git diff --name-only fishme-tout` ne montre que les dossiers permis.

## Pièges
- Une image d'une autre espèce par défaut. Parade : le test « image à venir ».
- Toucher un dossier d'un autre lot. Parade : le crochet de git refuse le commit.
- Écrire « autorisé » ou « allowed » par réflexe. Parade : le `grep` du test.
- Compiler en même temps que les autres lots : un seul build à la fois (`mkdir /tmp/fishme-build.lock`, le retirer ensuite).
