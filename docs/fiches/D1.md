## Contrat
Fichiers à saisir, en mots (JSON = fichier texte structuré ; GeoJSON = JSON qui décrit points et contours) :
- `departements.geojson` : téléchargé (france-geojson, version simplifiée). Citer IGN et INSEE (Licence Ouverte).
- `coins-osm.geojson` : export d'Overpass Turbo (site qui exécute une requête OpenStreetMap), licence ODbL (celle de la base OpenStreetMap), « © contributeurs OpenStreetMap », fichier gardé à part. `coins-maison.json` : 30 à 60 coins d'accès public.
- `regles.json` : socle national (Légifrance, le site officiel du droit français : R436-6, -7, -13, -14, -18, -21) et arrêtés (décisions des préfets) des 5 départements (75, 92, 93, 94, 77). Une règle a : identifiant, portée, espèces, catégorie, type (taille_min, quota_jour, ouverture, horaire, interdit, reserve, consommation), valeur, du, au, règle remplacée, phrase, source (texte, lien, lu_le, version), statut (saisi, verifie, incertain).
- `especes.json` (14 espèces : nom, nom latin, numéro TAXREF du référentiel des noms d'espèces, code Sandre du référentiel de l'eau), `credits.json` (les mentions exigées par les licences : OpenStreetMap, IGN et INSEE, OFB ; la page Sources de L6 le lit), `silhouettes/*.svg` (un trait, un profil, à caler avec le fil Maquettes).
- Échecs : texte illisible ou deux sources qui divergent = statut `incertain`, jamais une valeur devinée ; une règle `incertain` n'autorise jamais « tu peux la garder ». Les saisons s'écrivent en dates, pas en phrase.
