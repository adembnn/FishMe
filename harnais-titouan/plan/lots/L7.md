## Objectif
Stockage JSON atomique, reprise après arrêt brutal (E8), corbeille 30 jours (E16), réglages persistés. Ajouts par rapport à 04 : brouillon de capture, suppression douce, SettingsStore.

## Périmètre de fichiers strict
Fichiers que ce lot a le droit de **créer ou modifier** (chemins depuis la racine du dépôt) :
- `PecheCore/Sources/PecheCore/Store/{JSONCollectionStore,CollectionSnapshot,Migrations,DraftStore,SettingsStore}.swift`
- `PecheCore/Tests/PecheCoreTests/StoreTests*.swift`

Fichiers **explicitement interdits** pour ce lot :
- Contracts (sauf PR)
- SwiftData, CloudKit
- Écriture de photos (PhotoPreprocessor est dans PecheApple, L14)
- Tout fichier hors du périmètre ci-dessus, en particulier les fichiers d'un autre lot du tableau plan/SUIVI.md (un fichier = un propriétaire).
- `PecheCore/Sources/PecheCore/Contracts/` : gelé jeudi 10 h ; après le gel, ajout additif par PR relue par Adem et Titouan, jamais de renommage ni de suppression silencieux.
- `project.yml`, `ci_scripts/`, `.github/workflows/` (Adem seul, sauf mention contraire).
- Les fichiers `*PlaceholderView.swift` du dossier du lot : le lot les remplace ou les supprime, personne d'autre n'y touche.
- Toute dépendance externe (SPM tiers, SDK d'analytics) : interdit. Mots « Pokémon » et « Pokédex » : interdits partout.

## Interface publique à respecter
- `JSONCollectionStore: CollectionStore` (écriture atomique, `schemaVersion`, migration v1 vers v2).
- `DraftStore` : état de capture en cours (photo originale écrite avant analyse, espèce choisie, taille) pour reprise au même écran.
- `softDelete`/`restore`/`purgeExpired(30 j)`.
- Chaque sauvegarde émet `AppEvent.cardSaved`/`cardEdited`/`cardDeleted`.

## Critères d'acceptation vérifiables
- Relecture identique ; migration testée ; 1 000 prises < 100 ms.
- Test de kill simulé : fichier jamais corrompu (écriture atomique).
- Corbeille : une prise supprimée est restaurable pendant 30 jours.
