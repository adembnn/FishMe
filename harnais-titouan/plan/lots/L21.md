- `LegalTexts` : `localRuleDisclaimer`, `responsibleNotice`, `rarityBiasNotice`, `sourcesAttribution` (« Source : OFB - ASPE via Hub'Eau, Licence Ouverte 2.0 »).
- Texte fixe : « Cette application ne connaît pas les règles de pêche locales et ne dit jamais si une prise est légale. Consulte la fédération de pêche de ton département. »
- Les chaînes affichées viennent de `docs/copy/ui-strings-fr.json` (déjà écrit) : `LegalTexts` les lit ou les recopie sans les modifier.
